Description:
   This program is written in C using the library raylib so you can have a nice
   UI and GUI to listen to your legally acquired .mp3, .wav, and .ogg. 

   * To compile on MacOS:
      `gcc mp3App.c getSongs.c-o mp3PlayerApp $(pkg-config --libs --cflags raylib)`
      `./mp3PlayerApp`

   * To compile on Linux:
      `Work in progress`

   * To compile on Windows
      `Not working in progress`
-------------------------------------------------------------------------------
How to use:
   1. Make sure raylib is downloaded
      * https://www.raylib.com/

   2. Create a "cSongs" folder (named exactly like that)
      * Be careful! It must be in the same directory of the main source code

   3. Run the given compile and run command 

   4. Listen to the music as you desire
